───────────────────────────────────────────────────────────────────────────────
OPTION 1: DOCKER (Testing/Flexible Deployment)
───────────────────────────────────────────────────────────────────────────────

When to use: Testing locally, deploying to multiple machines, quick setup

Steps:
  1. Copy to target:
     scp -r ~/projects/mansionradio user@target:~/

  2. Configure:
     cd mansionradio
     cp .env.example .env
     nano .env  # Edit if needed

  3. Deploy:
     docker-compose up --build -d

  4. Monitor:
     docker-compose logs -f

  5. Stop:
     docker-compose down

Documentation: docs/DEPLOY_DOCKER.md

───────────────────────────────────────────────────────────────────────────────
OPTION 2: BARE METAL (Production, Like Eggdrops) ⭐ RECOMMENDED
───────────────────────────────────────────────────────────────────────────────

When to use: Pi3 or Ubuntu VM, minimal overhead, like eggdrop setup

Steps:
  1. Copy to target:
     scp -r ~/projects/mansionradio user@pi3:~/

  2. SSH and setup:
     ssh user@pi3
     cd mansionradio
     bash setup.sh

  3. Configure:
     nano .env  # Edit if needed

  4. Install systemd service:
     sudo cp systemd/mansion-radio-bot.service /etc/systemd/system/
     sudo systemctl daemon-reload
     sudo systemctl enable mansion-radio-bot
     sudo systemctl start mansion-radio-bot

  5. Verify:
     sudo systemctl status mansion-radio-bot
     journalctl -u mansion-radio-bot -f

Management Commands:
  • Start:   systemctl start mansion-radio-bot
  • Stop:    systemctl stop mansion-radio-bot
  • Status:  systemctl status mansion-radio-bot
  • Logs:    journalctl -u mansion-radio-bot -f
  • Restart: systemctl restart mansion-radio-bot

Documentation: docs/DEPLOY_BAREMETAL.md
